# NextLevel Website

A responsive, dark-blue website starter for a technology and digital services company. Built with plain HTML, CSS and JavaScript so it is easy to edit and host on GitHub Pages.

## Files
- `index.html` — page content and sections
- `style.css` — colours, layout, responsive styling and visual components
- `script.js` — mobile navigation, active section links, footer year and contact email draft

## Preview locally
1. Download and unzip the project.
2. Open `index.html` in a browser.
3. For a better developer workflow, open the folder in Visual Studio Code and use a local preview extension such as Live Server.

## Publish with GitHub Pages
1. Sign in at https://github.com and create a new repository, for example `nextlevel-website`.
2. Upload `index.html`, `style.css`, `script.js` and this README to the repository's root folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for the Pages deployment to finish. GitHub will show the public website URL in the Pages section.

## Important edits before publishing
1. In `index.html`, replace `hello@nextlevel.example` with your real business email in both the contact link and the contact form instructions.
2. Update the company description and services to match what NextLevel genuinely offers.
3. The three project cards are explicitly marked as **concepts**. Replace them with your own real projects and screenshots as you complete them; don't present mockups as completed client work.
4. If you want the contact form to submit directly without opening a visitor's email app, connect it to a form backend or service. This starter does not store data or send messages to a server.
5. Google Fonts are loaded online. The page will use fallback fonts if they are unavailable.

## Customise the branding
The primary colours are defined at the top of `style.css` in `:root`. Change `--blue` and `--cyan` to adjust the accent colours.
